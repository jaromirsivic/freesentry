# B0 baseline – XTX3 re-measured with the XTX4 evaluator

Generated by `scripts/evaluate.py` (metric: `xtx4/engine/metrics.py`, CONTRACTS §9). Raw reports: `reports/B0_*.json`.

**Setup.** Full test split `D:/xtxtraining/test`: 11,320 images, 30,078 persons. 1,048 persons have none of the
9 landmarks labeled; they are ignore regions (COCO `num_keypoints == 0` rule), which leaves **29,030 GT**. No crowd
annotations exist in this split. GT `area` = person box area (`area_source: "bbox"`, XTX3 legacy). Predictions come from
`xtx3.api` (`load_model(fuse=True)`, `detect_poses` replicated batch-wise with a parity check: same detection counts,
max |Δscore| ≤ 4e-4, max |Δxy| ≤ 0.4 px). Score ≥ 0.001, maxDet 100 (AP9_project). Weights:
xtx3-u `best.pt` sha256 `b403f159…d455e7`, xtx3-n `best.pt` sha256 `ef462e1c…cf82fb`.

* `preds = api` is the public pipeline. `preds = raw_o2o` is the one-to-one head **before** `merge_views` (whole mode only).
* AP coco20 = the same metric with maxDet 20. coco ΔAP = ours(maxDet 20) − pycocotools on the first 500 images
  (9 sigmas, built in memory).
* face buckets are in network px (face spread × min(1, S/max(w,h))), so the bucket populations change with S.
* img/s is end-to-end (JPEG decode + letterbox + forward + decode + Python merge, batch 16, shared RTX 4070). It is
  not model speed.

## Findings

1. **The historical number is reproduced exactly, and AP75 can now be measured.** On the first 200 test images at
   conf 0.05, the XTX3 evaluator gives AP 0.4589 / AP50 0.7064 / AP75 **0.0000** / AR 0.5730, matching `train.log`.
   The XTX4 evaluator on the same predictions gives AP 0.4750 / AP50 0.7315 / AP75 **0.4743** / AR 0.5931. All of the
   +0.016 AP comes from the 20 GTs with no labeled landmark: XTX3 counts them as FN (589 vs 569 GT). Lowering the
   score threshold from 0.05 to 0.001 adds only +0.0001.
2. **B0 (xtx3-u, full split): AP 0.4720, AP50 0.7097, AP75 0.4970, AR 0.5891 at S=320.** At S=384, AP is the same
   (0.4711) but AP75 (0.5033), AR (0.6034) and recall on faces under 8 px (0.756 vs 0.703) are higher. At S=256, AP drops by
   0.024. The 200-image validation used for `best.pt` (D2) overestimated full-split AP by only about 0.003.
3. **XTX3 is not NMS-free in practice.** `merge_views` also runs in whole mode. It greedily suppresses detections
   with OKS ≥ 0.5 or box IoU ≥ 0.5, which is an NMS. Without it, the one-to-one head gives **3.2 duplicates per image
   at conf 0.25** (67 % of all FPs). AP drops from 0.472 to 0.425 and AP50 from 0.710 to 0.602. AR rises to 0.68
   because the suppression also removes some true positives in crowds (5+ persons: recall 0.676 merged vs 0.703 raw).
   XTX4's one-to-one head must close this gap by itself (plan §6.5).
4. **With the merge step, FPs at conf 0.25 are mostly background or badly localised, not duplicates:** 9,631 FP
   = 6,339 background (best OKS < 0.1) + 3,197 localisation (0.1–0.5) + 95 duplicates. P/R@0.25 = 0.685/0.722.
   At conf 0.05 precision is 0.12 (the 87 % FP share in the old report). Most of these are low-score background,
   which costs little AP.
5. **Small faces and difficult scenes are the weak spots (S=320, conf 0.25).** Face recall is 0.70 / 0.81 / 0.87 / 0.81
   for face spread < 8 / 8–16 / 16–32 / ≥ 32 network px. Face-PCK@0.1·spread is 0.08 for faces under 8 px and 0.28
   overall. Persons near the image edge have recall 0.60 vs 0.75 for interior persons. Crowded images (5+ persons) have
   recall 0.68 vs 0.79 for single-person images.
6. **Visibility head:** macro-F1 0.548. The occluded class is almost never predicted (F1 0.04; absent 0.71,
   visible 0.89). Ears and hips have the lowest visibility accuracy (0.76 / 0.78). This is consistent with D5
   (v=0 trained as "absent").
7. **xtx3-n (epoch 23, incomplete training)** reaches AP 0.291 whole / 0.271 pyramid at 384. Pyramid is worse and
   3.5× slower (D7 confirmed). Its scores are compressed: at conf 0.25 recall is only 0.03–0.05, so the @0.25
   columns are not meaningful for xtx3-n. At conf 0.05 recall is 0.68.
8. **pycocotools cross-check:** |ΔAP|, |ΔAP50|, |ΔAP75|, |ΔAR| < 1e-15 on the first 500 images for every run.
   The evaluator matches COCOeval exactly (same matching, crowd handling and 101-point interpolation).
